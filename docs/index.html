安装方法
  1. 点击上方"下载 PixelPet"按钮，下载 PixelPet-1.0.0.zip
  2. 解压 zip，将 PixelPet.app 拖入"应用程序"文件夹
  3. 第一次打开时右键点击 App → 选"打开" → 点"打开"确认
  4. 之后就可以直接双击打开，自动更新也会正常工作
为什么需要右键打开？
因为这个版本没有 Apple 开发者证书签名，macOS 会提示"无法验证开发者"。右键→打开是绕过这个提示的标准方式，完全安全。
